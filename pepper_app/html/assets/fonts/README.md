# Heading fonts

The stylesheet asks for **Europa Grotesk SH Bold** first, then **Grotesk**
(SoftMaker), then falls back to `"Arial Narrow", Arial, sans-serif`.

- `Grotesk-Medium.ttf` is committed and served with the app (web and Pepper
  tablet). It is included for this non-commercial research project at the
  project owner's direction. Check the SoftMaker licence before any other use.
- Europa Grotesk SH is not included. To use it, add
  `EuropaGroteskSH-Bold.woff2` and/or `EuropaGroteskSH-Bold.woff` here. These
  files are git-ignored, so they stay local unless you deliberately un-ignore
  them. A copy installed on the device is also picked up through `local()`.
